# Maison Aurelle

Завершена портфолійна концепція вигаданого бутик-готелю в Карпатах. Увесь інтерфейс українською. Без фреймворків, встановлення залежностей, зовнішніх запитів під час перегляду, платежів чи надсилання даних.

## Перегляд

Відкрийте `dist/index.html` у браузері або виконайте `npm start` у цій папці та перейдіть на `http://127.0.0.1:4173`.

## Файли

- `dist/index.html` — усі розділи та тексти.
- `dist/styles.css` — адаптивне оформлення, контрольні ширини 560, 850 і 1100 px.
- `dist/app.js` — мобільне меню, доступні діалогові вікна, галерея, перевірка дат.
- `dist/assets/` — локальні фотографії, шрифт і піктограма.
- `server.cjs` — локальний сервер без залежностей, доступний лише через loopback.

Форма працює виключно в браузері. Вона перевіряє обов’язкові дати, забороняє минулий заїзд та виїзд не пізніше за заїзд і показує пояснення демонстраційного режиму. Дані не зберігаються й не передаються.

Назви номерів локалізовано: Panorama Suite → «Панорамний люкс», Forest Deluxe → «Лісовий делюкс», Aurelle Residence → «Резиденція Орель». Оригінальні ідентифікатори збережені в атрибутах `data-room-name`.

Номери, площі, ціни, послуги, відгуки та контактні дані вигадані. Фотографії ілюструють атмосферу, а не реальний готель. Соціальні кнопки відкривають пояснення демонстраційного режиму.
